# 论文模式样例外

这些 DOCX 是**合成样例**，不含真实学生论文或个人信息，用于：

- 验证 DOCX 解析不丢正文、标题、表格与节属性；
- 验证格式规则不会在干净样例上误报；
- 演示「导入 → 检查 → 问题清单」的最小闭环。

| 文件 | 用途 | 预期问题 |
|---|---|---|
| `clean-sample.docx` | 干净样例 | 0 个格式问题 |
| `format-problem.docx` | 页面与页边距违规 | 纸张不是 A4、页边距不符合示例模板 |
| `structure-problem.docx` | 标题结构问题 | 标题层级跳跃、疑似漏设标题样式 |
| `citation-problem.docx` | 引用 L1 问题 | 首次出现顺序颠倒、引用缺号、参考文献条目重复 |

重新生成：

```bash
python thesis-samples/generate_samples.py
```

## 注意

- 这些样例只用于开发测试，不代表任何学校的真实格式要求。
- 贡献真实学校的模板前，请先确认来源公开可引用或已获授权，并移除学生个人信息。
- 论文模式不会修改原文件；导入时计算 SHA-256，检查与修复都基于副本。
