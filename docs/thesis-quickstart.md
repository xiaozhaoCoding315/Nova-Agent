# 论文模式 5 分钟上手

论文模式面向本科/研究生的毕业论文与毕业设计。核心是**定稿前体检**，并提供基于真实项目的 AI 写作助手；它不直接改写你的 DOCX 正文，做五件事：

1. 按模板检查页面、页边距、标题层级、页码和必需章节；
2. 核对文内引用与文末参考文献（L1），可选联网核验 DOI 元数据（L2），可选从你自带的 PDF 中定位候选原文（L3）；
3. 记录 AI 使用情况并导出声明；
4. 把修复版 DOCX、体检报告、引用清单、声明和修改记录打成一个定稿包；
5. 关联工程仓库或本机文件夹，让 AI 读代码、梳理项目、起草带依据的章节草稿。

> 不做代写整篇论文、降重、降 AIGC、查重、伪造引用，也不抓取知网/维普/万方。AI 生成的正文是草稿，必须由你本人核对、修改并署名。报告是本地检查记录，不是学校出具的合规证明。

## 0. 准备

- Windows 桌面版（推荐），或按 [README](../README.md) 用 Docker/源码启动；
- 论文源文件：`.docx`。`.doc` 请先在 Word/WPS 中另存为 `.docx`；
- 不需要 API Key。格式检查、引用 L1、AI 声明、报告导出全部离线可用；
- 引用 L2 需要能访问 `api.crossref.org`，且只发送 DOI；引用 L3 只在本机读取你附加的 PDF。

## 1. 切换到论文模式

在顶栏把「开发 / 论文」切到「论文」。切换会记住，刷新后仍保持；开发模式的功能不受影响。

## 2. 新建论文项目

填写论文题目（必填）、学校、学位，并选择模板。

- 模板决定页边距、页面大小、标题层级、页码、必需章节和参考文献要求；
- 仓库自带 3 个**虚构演示模板**，用于体验流程，不对应任何真实学校；
- 找不到学校模板时先用演示模板，或按 [模板作者指南](thesis-template-guide.md) 提交模板。

## 3. 导入 DOCX

选择文件导入。Nova 会把它复制到项目目录并计算 SHA-256；**原文件只读，永远不会被原地修改**。解析失败会显示可读原因，不会只抛一个异常。

## 4. 关联工程项目与 AI 写作（可选）

右侧「AI 写作助手」常驻可用，对话历史按论文项目独立保存，不会出现在开发模式的会话列表里。切换「开发 / 论文」也不会把两边的历史混在一起。

- **关联已有项目**：「写作」页点「关联已有项目」，选择你在 Nova 里已有的仓库（ZIP / Git / 本地文件夹）。
- **打开本地文件夹**：桌面客户端本地模式可直接登记本机目录，例如 `D:\code\my-graduation-project`。它与开发模式使用同一套本机执行器：原地读写、不复制文件、无容器隔离，修改直接落在你的目录里。
- **权限**：对话顶栏选择「只读 / 询问 / 自动 / 完全」。只读模式绝不写文件；询问模式每次写文件或执行命令前都要你批准。它不会擅自修改论文 DOCX 或你没点名的文件。
- **上下文**：每次对话自动带上论文题目、项目说明、最新 DOCX 统计与提纲、未处理问题和已导入的参考文献编号；代码里的技术事实要求给出 `文件路径:行号`。
- **写作边界**：AI 只使用你导入的参考文献，不编造文献、DOI、数据或实验结果；生成的正文标注「AI 草稿，需本人核对与改写」。请把每次 AI 参与如实记入「AI 使用声明」。

不想让 AI 碰项目文件时，把权限切到「只读」即可；体检、修复、引用核对不需要模型。

## 5. 运行检查

点「运行检查」。问题按 `阻断 / 警告 / 提示` 分级，每条都带：

- 规则 ID 与说明；
- 位置（节、段落或全文）；
- 当前值与建议值；
- 依据（模板 ID/版本或规则来源）；
- 置信度。

没有 Key、断网也能完成这一步。

## 6. 逐条处理问题

- **预览修复**：先看修复前后的值和内容校验结果；
- **应用修复**：只改页面大小、页边距、标题样式等属性，不改正文；修复写入 `working.docx` 并保留版本备份；
- **撤销修复**：按修改记录回滚；
- **忽略**：确认是误报或学校另有要求时标记忽略，报告里会保留状态。

修复后会重新解析文档，段落数和字数异常减少会被拒绝。目录、交叉引用等 Word 域请在 Word 中按 **F9** 更新。

## 7. 引用核对

### L1（自动，离线）

解析数字编号 `[1]`、`[1-3]`、作者-年份 `（张三，2020）` / `(Smith, 2020)` 与文末参考文献，报告缺条目、重复条目、编号不连续、首次出现顺序等问题。

### L2（可选，联网）

点「联网核验 DOI」。Nova 只从条目中提取 DOI 并发往 Crossref，不发送论文正文；结果缓存 30 天。状态含义：

| 状态 | 含义 |
|---|---|
| 已核实 | DOI 可解析，题名与年份一致 |
| 部分匹配 | DOI 可解析，但题名/年份有差异，或中文题名无法逐字比对 |
| 信息不符 | Crossref 题名或年份与条目明显不一致 |
| 未找到 | Crossref 查不到该 DOI；**不等于文献是伪造的** |
| 需人工确认 | 联网失败或结果不确定 |
| 无 DOI | 条目中没有 DOI，未联网 |

### L3（实验，离线）

在「引用」页附加你手头有授权的参考文献 PDF，点「定位候选页码」。Nova 在本机提取文字层，按 DOI、题名或关键词找到候选页和原文片段。

- 只给候选，**不判断引用是否恰当**；支持度由你在表格里选择；
- 扫描版 PDF（没有文字层）无法定位；
- PDF 仅保存在本项目目录，删除 PDF 会同时删除相关候选证据。

## 8. 登记 AI 使用情况

在「AI 使用声明」页如实登记工具、版本、使用环节、用途、生成内容和你的修改情况。导出的是学校要求的声明草稿；姓名、学号与签名需要你在 Word 中补全。

Nova 不做 AIGC 检测，也不会帮你掩盖使用痕迹。

## 9. 导出定稿包

在「导出」页生成 ZIP，包含：

```text
<论文名>_定稿包/
├─ <论文名>_修复版.docx
├─ 论文体检报告.docx / .html
├─ 引用核验清单.csv
├─ AI使用声明.docx
├─ 修改记录.json
└─ 提交说明.md
```

报告包含模板版本、扫描时间、问题清单、证据、修复状态、引用 L1/L2/L3 状态、局限和人工确认项。

## 没有 Key / 断网能做什么

| 能力 | 无 Key | 断网 |
|---|---|---|
| DOCX 导入与解析 | 可用 | 可用 |
| 格式体检与报告 | 可用 | 可用 |
| 预览/应用/撤销修复 | 可用 | 可用 |
| 引用 L1 | 可用 | 可用 |
| 引用 L2（DOI） | 可用（需联网） | 不可用，自动降级为「需人工确认」 |
| 引用 L3（PDF 定位） | 可用 | 可用 |
| AI 声明与定稿包 | 可用 | 可用 |
| AI 写作助手（读项目/起草） | 需配置模型 | 需配置模型 |

## FAQ

**会改我的原文件吗？**
不会。原文件只读；修复写入 `working.docx`，每次修复前有备份，可撤销。

**为什么目录/页码在 Word 里没变？**
Nova 改的是结构属性，预览/导出后请在 Word 中全选按 F9 更新域。报告明确标注「未做页面渲染级校验」。

**为什么不检查字体、字号、行距？**
当前版本只做有明确结构证据的规则，避免误报。字体/字号/行距需要页面渲染级校验，后续版本再评估；请按学校要求人工确认。

**误报怎么办？**
可以忽略该条；如果是规则问题，请按 Issue 模板提交规则 ID、位置、当前值和依据。

**引用 L2 会把论文传到网上吗？**
不会。只发送条目里的 DOI，不发送题名、作者、正文或文件；结果缓存 30 天。

**「未找到」是不是说明文献造假？**
不是。Crossref 覆盖不全，中文文献、会议论文和书籍尤其常见；请人工确认。

**可以用学校模板吗？**
模板只编码可执行的规则，不搬运学校格式文件原文。仓库内置模板是虚构演示校；真实学校模板需要来源说明并通过 CI 校验。

**论文对话会出现在开发模式里吗？**
不会。论文对话按项目和 `product_mode='thesis'` 存储，开发模式只列出开发会话；切回论文模式时，再从当前项目的历史里选择。

**AI 会改我的项目代码吗？**
只在「询问」模式下经你批准，或你主动选「自动 / 完全」时才会写；「只读」只读不写。AI 不会擅自改动论文 DOCX 或你没点名的文件。

**数据存在哪里？**
所有项目文件在本地用户数据目录下（`data/users/<user_id>/thesis/<project_id>/`，桌面版为应用数据目录）。Nova 默认无遥测；只有你主动点「联网核验 DOI」时才会访问 Crossref；AI 对话只把你发送的内容发给你配置的模型端点。

**能边写边用吗？**
可以。AI 写作助手能基于关联项目起草章节草稿，正文修改仍在 Word/WPS 完成；建议定稿前、每次大改后各跑一次体检。
